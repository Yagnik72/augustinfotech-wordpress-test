# WP Referral System

A WordPress plugin for managing referral system with commission tracking.

## Features

- User registration with referral code validation
- Real-time referral code validation using AJAX
- Referral history tracking
- Commission management
- Admin dashboard with statistics
- Customizable join commission
- WP List Table for managing referrals
- Translation ready

## Installation

1. Upload the `wp-referral-system` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Referral System' in the admin menu to configure settings

## Usage

### Shortcode

Use the following shortcode to display the registration form:

```
[wp_referral_form]
```

### Admin Features

1. **Dashboard**
   - View total referrals
   - View total commission
   - See recent referrals

2. **Referral History**
   - View all referrals
   - Search referrals
   - Edit/Delete referrals
   - Bulk actions

3. **Settings**
   - Configure join commission
   - Get shortcode for registration form

### Frontend Features

1. **Registration Form**
   - First name
   - Last name
   - Email
   - Password
   - Referral code (optional)
   - Real-time referral code validation

2. **Referral Code Validation**
   - Real-time validation using AJAX
   - Visual feedback for valid/invalid codes

## Requirements

- WordPress 5.0 or higher
- PHP 7.0 or higher
